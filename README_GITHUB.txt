GITHUB PAGES DEPLOYMENT

IMPORTANT: Keep this exact folder structure in the ROOT of your GitHub repository:

index.html
assets/
  confident-poster.jpeg
  strawberry-matcha.jpeg
  aspect-minds.jpeg
  portfolio-wireframe.jpeg
  starbucks-promo.jpeg

HOW TO UPLOAD:
1. Open your GitHub repository.
2. Choose Add file > Upload files.
3. Upload index.html AND the entire assets folder (with all 5 images).
4. Commit changes.
5. Open Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Select branch main and folder /(root), then Save.
8. Wait for GitHub Pages to publish.

Do not upload only index.html. The images are loaded from the relative assets/ folder.
File names are case-sensitive; do not rename the image files unless you also update index.html.
